# Latviska izteiksme

Claude skill, kas pārraksta AI radītu vai stīvu tekstu dabiskā, cilvēciskā latviešu valodā: ievēro latviešu gramatiku un stilu, nelieto garo domuzīmi un vidējo lieto tikai reti.

## Uzstādīšana

**Claude Code:** nokopē mapi uz `~/.claude/skills/latviska-izteiksme/` (lai `SKILL.md` atrastos tajā).

```bash
git clone https://github.com/Deniss177/latviska-izteiksme ~/.claude/skills/latviska-izteiksme
```

**Claude.ai:** Settings → Capabilities → Skills → augšupielādē šo mapi kā ZIP.

## Lietošana

```
/latviska-izteiksme pārraksti šo tekstu: ...
```

Vai vienkārši palūdz Claude padarīt tekstu dabiskāku vai latviskāku.
